# ADR-0008: 远端经系统 ssh，推送静态 server

- 状态：已采纳
- 日期：2026-10-27
- 依据：[remote.md](../remote.md)

## 决定

- **传输**：只用系统 `ssh`。认证、密钥、`known_hosts`、跳板机交给它。
- **交付**：首次连接探测架构，推送对应 `musl` 静态二进制，在远端跑通 `--version` 才上线。
  远端已有能执行、协议大版本相同的 server 就直接用。执行前打印命令与版本；只留两版。
- **三档对接**（自动探测并明示）：A `ssh host pigeon-server --proxy`（stdio 桥接，推荐）→
  B unix socket 直转 → C 普通 ssh（退化模式，状态可见但不持久）。
- **权限**：远端只监听 0700 的 unix socket。

## 约束

- 不开网络端口，不接受密码。
- 不改远端 shell 配置，不静默覆盖已有版本。
- 客户端显示当前用的是哪一档。

## 已知限制

C 档受 `ssh -tt` 的固定 80×24 pty 限制：客户端没有本地 pty 转发 `TIOCSWINSZ`，
窗口再大远端也只按 80 列换行（[plan.md §11](../plan.md)）。

## 何时重开

需要 ssh 之外的传输通道时，作为新增一档，不替换 ssh。
