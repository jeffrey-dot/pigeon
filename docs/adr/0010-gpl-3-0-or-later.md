# ADR-0010: 许可证 GPL-3.0-or-later

- 状态：已采纳
- 日期：2026-10-27
- 依据：[`LICENSE`](../../LICENSE)、[plan.md §9.5](../plan.md)、[AGENTS.md §9](../../AGENTS.md)

## 决定

**GPL-3.0-or-later**。

## 约束

- 依赖必须与 GPLv3 兼容：MIT / Apache-2.0 / BSD / ISC 可用，LGPL 限动态链接。
  CDDL / EPL 不可静态链接。
- 借鉴其它实现只借思路与规格；逐行复制需要同许可证，并在文件头注明来源。
- 纯规格（OSC 7501 文档、我们自己的实测记录）不受此限。

## 何时重开

不重开。
